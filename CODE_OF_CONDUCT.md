# Community code of conduct

PageSquire welcomes people of every background and experience level. Use clear, respectful English for canonical project discussions; help contributors who are not native English speakers.

## Expected behavior

Be constructive, respect differing experiences, give actionable technical feedback and acknowledge mistakes. Review code and evidence, not a person's identity or worth. Respect privacy and accessibility needs. Do not post credentials, private website exports or real visitor data.

Harassment, discrimination, threats, sexualized attention, doxxing, sustained personal attacks, impersonation and deliberate disruption are not acceptable. These rules apply in project issues, pull requests and other spaces maintained for PageSquire, including when representing the project elsewhere.

## Moderation and reporting

The repository owner is the initial maintainer. Maintainers may edit/remove harmful content, restrict participation, or temporarily/permanently exclude participants. Decisions should be proportionate to severity, impact and repeated behavior; explain decisions privately when doing so does not endanger others. Maintainers are bound by the same standards and must avoid handling conflicts in which they are personally involved.

No project-specific private conduct-reporting contact is configured yet. Do not post sensitive allegations publicly. Until a private contact is established, use the hosting platform's private abuse-reporting tools for platform violations. A reporter may request review by another uninvolved maintainer when one is appointed; no independent appeals body or response-time guarantee is promised.

Before opening the community publicly, the owner must establish a reachable private conduct channel and update this file. Security vulnerabilities use the separate process in [SECURITY.md](SECURITY.md).
